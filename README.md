# Aindram Vedic Calendar

**Download:** [aindram-vedic-calendar.zip](https://github.com/technologistkj/vedic-calendar-wordpress-plugin/releases/latest/download/aindram-vedic-calendar.zip)
(latest release). In WordPress: Plugins > Add New > Upload Plugin, choose the zip, Install, Activate.
Use that zip, not GitHub's "Source code" download, which unpacks to the wrong folder name.

WordPress plugin: shows the Vedic date (Kerala solar month by its Sanskrit name, day,
KaliYuga year from Vishu) on its own line below the date of every post and page.

- `includes/class-aindram-vedic-calendar-astronomy.php` — the arithmetic, plain PHP.
- `includes/vsop87-earth-l.php` — generated by `bin/gen-vsop.py`; do not edit.
- `includes/class-aindram-vedic-calendar.php` — the front end (date filters, block filter, loop buffer).
- `tests/` — `make_fixture.py` writes the Swiss Ephemeris oracle; `test-astronomy.php` must match it:

      docker run --rm -v "$PWD":/p -w /p php:7.2-cli php tests/test-astronomy.php

- `python3 bin/build-zip.py` builds `dist/aindram-vedic-calendar-<version>.zip`.
